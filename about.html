Chapter II / Behind the Sketchbook

Not born
knowing.
Built by learning.

My journey into software development began with curiosity, uncertainty, and a willingness to learn something completely new.

The first line of code changed everything. ↗

The road so far

A journey drawn one line at a time.

Every stage brought new challenges, new tools, and a clearer understanding of how software works.

01 / THE BEGINNING

Starting from zero.

I joined Life Choices Academy with no previous programming experience. Everything was unfamiliar, from the structure of a webpage to the logic behind a working application.

That unfamiliarity became the beginning of a new direction.

a blank page...
02 / THE FIRST BUILD

Learning the language of the web.

HTML gave my pages structure. CSS taught me how to shape an interface. JavaScript introduced logic, interaction, and the possibility of making a page respond.

I began to see how individual pieces could become a complete experience.

structure → style → behaviour
03 / BEHIND THE SCREEN

Discovering the backend.

As I learned Node.js, Express, MySQL, and REST APIs, I started understanding what happens after someone clicks a button.

I learned how requests travel, how data is stored, and why connecting the frontend and backend is essential to building useful software.

everything connects ↘
04 / BUILDING WITH OTHERS

From exercises to applications.

Team projects gave me practical experience with Git, collaboration, troubleshooting, and connecting different parts of an application.

In HR Tech Solutions, I worked on employee management and performance review functionality.

In WeConnect, I focused on orders, deliveries, location tracking, and the connection between buyers and suppliers.

built together!
05 / STILL LEARNING

The next line is unwritten.

I am continuing to develop my skills in frontend and backend development, improving how I structure code, solve problems, and build reliable applications.

My goal is not simply to make websites look good. It is to build software that works, solves problems, and continues improving through thoughtful iteration.

work in progress...
A note from the present

Code is the craft.
Drawing is the language.

Drawing has been part of my creative life, but this portfolio is about my development journey. I chose a sketchbook aesthetic because it reflects how I approach building software: start with an idea, experiment, refine, and bring it to life.

I am developing my abilities as a full-stack web developer while continuing to learn through practical projects, collaboration, and problem-solving.

The sketch is never the final destination.

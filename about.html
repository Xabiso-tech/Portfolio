01 — Foundation

Learning the frontend

The first step was understanding how a website is structured and presented. I learned semantic HTML, CSS layout and responsive design, then used JavaScript to make pages respond to user input and work with data.

Building small pages helped me connect markup, styling and browser behavior rather than treat them as separate topics. I also began using Git and GitHub to keep track of changes and collaborate on shared work.

02 — Broader tools

Programming and data

The curriculum expanded into Python and PHP, then SQL and MySQL. I learned to work with conditionals, functions and input validation, and to model data, query related records and handle invalid input deliberately.

I also worked with Vue and Bootstrap, learning how components and frameworks can support an interface while leaving the underlying structure and behavior my responsibility.

03 — Experimentation

Applying the fundamentals

The Workshop brings together independent studies and team applications. The gallery and product sites let me practise layout, responsive behavior and interaction; the booking form focused on labels, input types and browser validation.

Working through defects taught me to reproduce a problem, inspect the relevant markup or code, and verify a fix in context. That process continues to shape how I approach new features.

04 — Backend development

Working across the stack

On a four-person HR system project, I built the employee and performance review backend using Express and MySQL, then connected the corresponding frontend pages to those routes. This introduced me to controllers, models, parameterized queries and JWT-protected endpoints in a shared codebase.

In WeConnect, a B2B marketplace, I worked on orders, payments and delivery tracking. My contribution included backend routes and queries, location setup, and Vue pages connected to the API, including a Leaflet map for the latest courier position.

These projects made the relationship between interface, API and database concrete. A feature had to work across those boundaries and fit the team's existing structure.

I am continuing to develop as a full-stack web developer, with more depth to build in backend design, databases and application architecture.

05 — Professional development

Working well with others

Life Choices Academy also included personal-development training. Sessions with Coach Matika covered leadership principles, communication, transformation and coaching. That work complemented the technical training and helped me think more deliberately about collaboration and professional practice.

Interactive exercise

Python calculator

My clearest lesson from Python is how much easier error handling is when you validate deliberately instead of assuming input is sensible. This exercise runs in four modes: arithmetic, percentages, frame dimensions and common paper sizes.

graphite-calculator

The calculator is a browser-based JavaScript port of the Python exercise: skills/graphite-calculator.py. Division and modulo by zero are refused rather than guessed at, results that are not real numbers are reported as such, and the arithmetic chains left to right exactly as the file does it.

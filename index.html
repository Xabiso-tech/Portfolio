Learning through the work

The graphite studio is the visual language. The subject is how web applications are planned, built and improved.

At Life Choices Academy I moved from HTML, CSS and JavaScript fundamentals into programming, databases and application structure. Project work gave those topics practical context: interfaces had to use real data, and backend changes had to fit the way people used the product.

I use the same process across the work: understand the requirement, build a small piece, test it in context and revise what does not hold up. The projects here show that progression from frontend exercises to team applications with APIs and database-backed features.

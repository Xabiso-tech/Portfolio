PLATE 01 / FULL-STACK APPLICATION

WeConnect

Connecting businesses, orders and deliveries.

WeConnect is a business-to-business marketplace connecting small businesses with suppliers. It brings product discovery, ordering, payments and deliveries into one platform.

My work focused on the orders and delivery systems, backend integration, location setup and GPS tracking features.

Vue 3 Express MySQL REST APIs Leaflet

  • Developed order and delivery functionality for buyers and suppliers.

  • Implemented location setup and tracking functionality using mapping tools.
  • Connected Vue interfaces to backend APIs and worked with shared project data.
  • Collaborated through Git branches, code integration and debugging.

PLATE 02 / TEAM APPLICATION

HR Tech Solutions

Making workforce information manageable.

HR Tech Solutions is a workforce-management project covering employee information, performance reviews and other HR functions.

I worked on employee management and performance review features, including backend APIs and their frontend integration.
